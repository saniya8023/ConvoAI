# UI/UX Specification

## Layout

Single-page application.

---

## Components

- Conversation title
- Mentor circles
- Shared Conversation Panel
- Notes panel
- Voice controls
- Add Mentor button

---

# Conversation Flow

One shared conversation.

Mentors appear one after another inside the same conversation feed.

No separate mentor chat windows exist.

The interface behaves like a collaborative AI discussion panel.

## Animations

- Mentor appears with scale animation.
- Speaking mentor glows using role color.
- Microphone pulses while recording.
- Smooth transitions throughout UI.
